## 目的

GUI 默认窗口里主页一屏放下、不再滚动：7 张卡片合并为 6 张（3×2 两行整齐对称），
卡片与标题区收紧留白，窗口默认尺寸从 1280×860 缩到 1180×720。顺手修两个体验
瑕疵：卡片副行 7 处重复的「点击开始 →」换成有决策价值的模块规模信息；现场检测页
「步骤条通栏 + 表单限宽靠左」的失衡版式收进同一限宽容器。

**怎样看到生效**：打开 NetPulse GUI → 主页 6 张卡片两行排满、整页无滚动条；
第一张卡是「网页打开慢」；窗口明显更矮（1180×720）；终端菜单场景区变 4 行、
工具区键位变 5/6/7/A。

## 现状实测（2026-11-14，真实运行页面 1280×860 视口）

  一出现即溢出滚动。

- 现场检测页：`.g-steps` 通栏 1208px，`.g-form` 限宽 720px 靠左，左右失衡。
- 模块勾选面板内容高 1018px 超窗——它是滚动工作台，**本次不动**。
- 窗口默认 `--window-size=1280,860`（`_gui_launch_browser`）。

## 不做什么

- **诊断逻辑不动**：评分口径、规则实现、判级口径、豁免逻辑零变化；本次只改
  「场景 → 模块/规则」的映射表。
- **报告页/进度页/盯障三视图/模块面板结构不动**：不重排、不改信息层级
  （盯障实时页靠窗口变矮后自然无滚动，不加改动）。
- **导出链不动**：`render_report_html_customer` / golden 基线 / 现场检测四件套
  逐字节不变。
- **不加响应式断点**：不做媒体查询自适应（窗口可缩放是 Chrome app 窗口既有
  行为，不在本次范围）。
- **终端交互语义不变**：只改菜单行文案与键位编号，场景执行流程、键位行为
  模式（数字选场景、工具区入口）不变。
- **不新增 `LAST_RUN` 依赖**（收口规则延续）。

## 硬约束

- **页面渲染闸延续**：动态数据一律 `textContent`，`insertAdjacentHTML` 只准
  全大写零插值常量；无 `<iframe>`；页面不内嵌模块清单/色表（合并后的 11 项
  模块集是服务端数据，页面只消费下发的 `modules` 数量）。
- **状态色唯一来源** `STATUS_COLORS` 经 `/api/scenarios` 下发，不变。
- **`/api/run` 白名单语义不变**：`keys` 形态校验、`profile` 互斥校验、场景
  profile ∈ `DIAGNOSE_PROFILES`；`slow` 移除后自然被拒。
- **续跑点兼容**：旧续跑点 `profile:"slow"` 不得崩溃——续跑执行依据是 `keys`
  （profile 仅用于横幅展示），label 查不到时退化为通用文案（不显示英文 id）。
- **HTML 转义铁律**（`_html_esc` / `_html_attr`）对本次改动涉及的任何拼接生效。
- **离线零外链**：GUI 页面资产闸延续。
- **发版纪律**：版本号三处同步 + CHANGELOG + tag 只推 `github` remote。

## 术语

- **合并场景**：id `web`、标题「网页打开慢」的场景卡；模块集 = 原 slow ∪ 原 web
  （11 项），规则集 = 两者并集（7 条）。
- **主页一屏**：视口 1180×720 下 `documentElement.scrollHeight ≤ 720`，
  含续跑横幅可见时同样成立。
- **规模副行**：场景卡底部一行模块规模提示（「11 项模块」等），替代「点击开始 →」。
