怎么选

要稳、要零风险 → 选 A。与 GUI、PDF 报告、CLI 配色同源，只改点列就能上线，验收闸不用动。
要一眼看出是网络工具、要现代感 → 选 B。波形太像医疗，雷达弧才是网络语言；亮蓝在下载页最抓眼。
要图标直接讲产品灵魂 → 选 C。「结论先行 / 达标判定」被画出来了，但 16px 必须单独做简化版。
要对外品牌物料 → D 作字标，图形标仍选 A 或 B 搭配。两者分工，不必四选一。

选定后的落地路径（当前未改动任何运行时代码）

  1. 改 tests/_make_favicon.py 的 render(size)：SIZES = [16,24,32,48,64,128,256] 每帧按几何独立重绘，16/24 帧单独简化，不靠位图缩放。
  2. py tests/_make_favicon.py --embed 刷新 netpulse.py 里的 _FAVICON_B64（页面 data URI 零外链）。
  3. py -m unittest tests/test_v1264_favicon.py 过 P1–P4：单条 favicon link、载荷同源、含 256/48/32/16 帧、base64 < 64KB。
  4. py tests/_gui_icon_probe.py 实机读 Chromium --app 窗口 HICON，确认任务栏不是默认文档图标。
  5. EXE 图标：NetPulse.spec 的 EXE(...) 目前没有 icon= 参数，用的是 PyInstaller 默认图标；可一并指向同一份多尺寸 ICO。
  6. 客户报告页眉 / 宣传片用 D 字标（浅底原色、蓝头反白）；按 design_ref/README.md 的约定，定型后只保留选中的稿。

说明：表中「语言参考」指的是成熟产品的设计语言层面（圆角方块 + 单色符号、雷达波纹、圆环仪表、纯字标等通用手法），不是对其图标的复刻或逐像素考证；四套图形均为本次原创几何构造。预览页中的 16/24px 是浏览器对矢量的等比缩放示意，正式 ICO 会按项目约定逐帧独立重绘，小尺寸表现只会更好不会更差。竞品名称仅作风格定位参照，不涉及商标使用。
