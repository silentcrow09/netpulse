NPNetPulse 本地 GUI · 设计稿

v1 · 2026-11-12 · 选型稿：主界面 A / B 两案 + 进度 / 报告 / 现场检测公共页 · 全部界面为新增，不动任何现有能力 · 选型后另出 spec.md + verify.md 再实施

技术形态一句话：双击 NetPulse.exe → 本地服务自动启动 → 用 Edge 应用模式打开独立窗口（无地址栏、无标签页，任务栏有自己的图标，看起来就是一个桌面程序）。 窗口内为 1:1 真实字号与真实文案，可直接按此实现。第 1 / 2 节为主界面两案二选一；第 3–5 节为公共页面，按方案 A 语言绘制。

00总览 技术形态 · 新增内容清单 · 不变项

GUI 是新增的默认入口：exe 双击后进图形界面；终端菜单、CLI 参数照旧可用。窗口本体是 Edge 应用模式（--app），所以标题栏、最小化/最大化/关闭都是系统原生行为，不需要自己画窗口。

① 双击 NetPulse.exe现有 exe，不新增进程形态
装维人员桌面双击，和今天一样；UAC、权限逻辑全部不变。
→
② 本地服务自动起仅本机访问
exe 拉起 127.0.0.1 本地页面服务，不对外网开放；关窗即退出。
→
③ Edge 应用模式窗口--app
无地址栏、无标签页、独立任务栏图标——看起来就是一个桌面程序。
