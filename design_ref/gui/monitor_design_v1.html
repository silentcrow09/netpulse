00总览 技术形态 · 新增内容清单 · 不变项

持续盯障解决的是「偶发问题抓不到」：快诊断是跑一次快照，盯障是守一段时间。第 7 张卡与现有六张卡同款，点卡片进配置页；盯障进行中可以离开实时页（后台继续），结束后在本窗口直接看报告。三节界面与下方清单一一对应。

01配置页「开始一次盯障」 新增页面 · 单卡片表单，步骤感从简

只回答三个问题：盯多久、盯哪个外网目标、要不要主动负载。其余全部给默认值，改完点「开始盯障」就走。

  • 顶部大数字回答「盯了多久 / 还有多久」（tabular-nums，进度条同步 42%）；「连通率」为当前累计口径；「监测中」蓝徽章带呼吸点，表示实时页在前台运行。
  • 四路状态一行四格：✓ 绿 / ✗ 红，每格带丢包 / 失败计数。示例数据自洽——外网丢包 2 = 曲线中两个红圈；TCP 失败 2 次未恢复显示红色；网关 / DNS 全程正常 → 一次中断即可判断「问题在外网侧」。
  • 双曲线：藏青 = 网关、琥珀 = 外网。网关是毫秒级，贴着 0 轴属正常；外网中段一次约 42 秒故障段（延迟冲高到 300ms+ + 两个采样点丢失画红圈），红色标注与事件计数「中断 1」对应；后续一次约 120ms 的短促升高 = 高延迟的第 2 次，单点突刺 = 抖动 1 次。
  • 事件计数只是前台粗略提示（0 值灰色弱化），完整事件清单以结束报告为准；负载提示条仅在配置页打开主动负载时出现，时间数字为示意。
  • 「停止盯障」红色描边不抢主色：提前结束也生成报告；返回主页后盯障在后台继续，可随时回到本页。
