## 二、正文（首行即钩子）

兄弟，今天开始工具箱就只带这一个——NetPulse。

25MB 单文件 exe，双击就跑，零依赖。

📌 以前·痛点
- ping 通、DNS 通、用户说就是慢——找半天找不到根子
- 偶发掉线，跑过去时一切正常，走了又断
- 网页打不开但 ping 通——DNS 改了也没用
- 签约千兆，speedtest 测出来只有 94M
- 说不清的硬骨头，回去抓包分析耽误一整天

📌 现在·NetPulse 一件搞定
- 场景菜单一键跑（网络很慢 / 经常断网 / 网页打不开 / 游戏卡顿 / WiFi信号差）
- 8 条内置规则跨模块聚合，按严重度排序，每条结论带**证据链 + 置信度**
- **MTU 黑洞检测**——二分探测路径 MTU，PMTUD 黑洞直接揪出来
- **盯障模式 + 抓包取证**——管理员开一次 Npcap 装好，NetPulse 自己盯、自己抓、自己分析，事件切片 pcap Wireshark 直开
- **一句话报障卡**——现场一键复制，直接发客服、运营商、用户群

✅ 25MB · 单文件 · 零依赖

| 项 | v1 | v2 修订 |
|---|---|---|
| **受众口径** | 混入"客户能看 / 客服能转 / 客户打运营商客服" | 锁死装维视角（源码注释"报告受众是装维人员"）："自己看得懂 / 工单贴得上 / 用户拿得走" |

| **PMTU 三信号判定** | 错写"三个中两个" | 正确表述："A 单独命中，或 B 和 C 同时命中，判黑洞；只有 B，那是链路丢包，两码事" |
| **S5 数字矛盾** | 签约千兆测出 120M + 链路协商 100M（自相矛盾） | 修正：千兆只协商到百兆 → 测速最多 94 兆（与官方说明一致） |
| **MTU 修复改法** | 错写"一行 netsh 命令改完立马好" | 改为官方三条：本机降 MTU / 路由器配 MSS 钳制 / 联系机房核对通道 |
| **MTU 典型症状** | 缺失 | 补"网页打得开，图片 · 验证码加载不出" |
| **慢场景模块数** | "七八个" | 精确为 7 个（DIAGNOSE_PROFILES['slow']=7） |
| **S1 工具 emoji** | 🔧📏🪛💻（不搭） | 装维真实工具：光功率计 / 红光笔 / 网线钳 / 脚本 U 盘 |
| **S6 事件 emoji** | ⚡🔁🔍（emoji 变体风险） | 纯文字：中断 / 抖动 / PMTU |
| **S7 ghost** | 📋（emoji 渲染风险） | 文字"REPORT" |

## 附：v3 追加修订（用户网络专家审查反馈）

| 项 | v2 画面 | v3 修正 |
|---|---|---|
| **S4 路径 MTU 探测语义** | `1500✓ / 1400✓ / 1300✗超时 / 1280✓`（自相矛盾——1500 都能过却判 1280 受限） | `1500✗太大DF拒绝 / 1400✗ / 1300✗被丢 / 1280✓分界点`（单调自洽：> 路径 MTU 必拒，≤ 必过） |
| **S4 结论表述** | 路径 1280 / 本机 1500，差 220 → 通道 MTU 受限 | 路径 MTU 1280 ＜ 本机 1500（差 220 ≥ 阈值 100）→ 通道受限（加上阈值说明，依据 netpulse.py:10755 MTU_MISMATCH_MIN_DIFF=100） |
| **S5 第三张卡（Bufferbloat）** | "A 级 / 空闲 20ms → 负载 320ms / 本例无膨胀"（A 级却 20→320ms 严重膨胀，自相矛盾；且与旁白"这两样"不符） | 删除该卡，改为双卡布局。Bufferbloat 案例已在 S2 演示。 |
| **S5 标题** | "测速不达标 · 从链路到无线三层排查" | "千兆只协商到百兆？先查这两处"（更接地气，与双卡结构对齐） |
| **S5 旁白一致性** | 旁白只讲"两样"，画面三卡 → 冗余 | 双卡对应"两样"，逻辑自洽 |

> 教训：装维视觉得过去≠真自洽。数字画面必须经得起逐步反问：1500 都能过却判 1280 受限——技术审查一句话就戳穿。
